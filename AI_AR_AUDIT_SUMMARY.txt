================================================================================
THE GLOW BRAIN - CORE ARCHITECTURE
================================================================================

Location: lib/glow-brain.ts

What It Does:
  1. Stores user profile locally (skin tone, preferences, etc)
  2. Tracks every interaction (views, clicks, purchases)
  3. Trains ML model on-device from interactions
  4. Ranks products using trained model
  5. Generates recommendations
  6. Tracks progress from photos
  7. Works completely offline

Storage (IndexedDB):
  ├─ userProfile (100KB)
  ├─ interactions (50KB per 1,000 events)
  ├─ progressPhotos (500KB per photo)
  ├─ preferences (50KB)
  └─ trainedModel (500KB)
  Total: 2-5MB per user

Privacy:
  ✓ 100% local processing
  ✓ No personal data sent to server
  ✓ User can clear history anytime
  ✓ Trained model stays on device
  ✓ GDPR compliant

Usage Pattern:
  Initialize → User takes profile quiz → Start collecting interactions
  Every 50 interactions → Retrain model locally
  Model improves over time → Better recommendations

RISK ASSESSMENT & MITIGATION
================================================================================

HIGH RISKS:
  1. Camera Permissions Denial
     → Mitigation: Progressive enhancement - works without camera
  
  2. Facial Recognition Accuracy (especially dark skin tones)
     → Mitigation: Diverse training data, user verification, manual overrides
  
  3. Browser Support (WebGL not available on old devices)
     → Mitigation: Server-side fallback, graceful degradation

MEDIUM RISKS:
  1. Performance on low-end devices
     → Mitigation: Throttle to 15fps, move heavy compute to Web Worker
  
  2. Privacy Concerns from Users
     → Mitigation: Clear messaging, transparent local-only processing, audit option
  
  3. Library Licensing (face-api.js)
     → Mitigation: Evaluate MediaPipe as alternative

LOW RISKS:
  1. Model Training Convergence
     → Mitigation: Test with synthetic data, tune hyperparameters
  
  2. IndexedDB Storage Limits
     → Mitigation: Compress photos, limit history to 6 months
